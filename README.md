# 國文偵探社｜國中課本互動學習基地

線上體驗：https://wukang1220-lang.github.io/guowen-detective/

配合國中國文 7上～9下 課本與語文常識打造的互動偵探學習網站，包含：
- **123 件課本與專題案件**：4 分頁課本情報袋（課本重點、形音義與注釋翻翻卡、成語大進擊、偵探讀法筆記）＋ 1,250 道推理舉證題。
- **特訓競技場**：形音義閃電戰、成語＆詞義配對板、修辭偵測雷達、段考＆會考實戰模擬（A++～B 等第評定）。
- **個人化學習與閱讀輔具**：錯題鑑識室、16 枚偵探勳章、全站 5 段字體大小調整、輕量音效與瀏覽器自動存檔。
